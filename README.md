# Hypergeometric Distribution Calculator

This Python script calculates and visualizes the hypergeometric distribution probabilities for defective items in a sample.

## Features

- Calculates probabilities for defective items in a sample
- Computes statistical characteristics (mean, variance, standard deviation)
- Sorts probabilities from most to least likely
- Visualizes the probability distribution and cumulative probabilities
- User-friendly console interface with input validation

## Requirements

- Python 3.x
- math module (built-in)
- collections module (built-in)
- matplotlib
- numpy
